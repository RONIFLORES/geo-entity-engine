# GEO Entity Engine

Mini App de estruturação e validação de entidades semânticas (JSON-LD / Schema.org) com foco em GEO (Generative Engine Optimization).

## Funcionalidades
- Segmentação em 4 modelos operacionais (Comércio Local, Prestador, Liberal e Digital).
- Geração instantânea do bloco `<script type="application/ld+json">`.
- Integração semântica com Google Maps, delivery e redes sociais via `sameAs`.
- Preparado para deploy na Vercel e integração com Make.
